# 原创研究方向：先验证问题，再确定模型

更新时间：2026-10-15。状态：**候选假设，未定稿、未证明新颖、未训练**。

执行授权更新：用户已授权启动 B003，并持续授权本机项目内后续工作，无需逐批再次询问；每次训练最多50轮，连续3轮验证 AUC 无严格改善早停。仍先登记清单、预算、哈希与授权依据。最终测试须先冻结候选、检查点和分析方案，再按持续授权执行；付费云资源不在默认范围。

目标是在ASSISTments2009、ASSISTments2015和NIPS34的统一协议下取得可重复的AUC提升，或在事先登记的困难场景上解决一个可测量的问题。第一轮结果以2026-10-29为目标；不足以支持结论时延长研究，不降低证据标准。

## 1. 先确定的问题

只有题ID、KC和对错时，同一次错误可能来自知识不足、偶然失误，也可能来自训练中很少见的题目。研究问题是：**有限历史和稀疏题目证据下，怎样更新和使用学生状态，才能提高下一次预测的可靠性？**

二元作答日志通常不能直接识别“猜测”“粗心”“疲劳”的真实心理原因。因此，模型内部参数先解释为预测中的权重、残差或不确定度；没有独立标注或可识别性证据，不称为真实认知变量或固定心理测量参数。

第一阶段只使用三数据集共同拥有的信息。文本、解题过程、选项、真实时间间隔和跨数据集预训练均不是默认前提。AS2015若没有独立题目ID，应承认其信息边界，不能把KC重新命名成题目就声称获得题目级证据。

## 2. 假设A：根据历史证据强度调整状态更新

**最新判断：当前证据不足以选为原创主线。** [专项核查](evidence/CAUSAL_UPDATE_NOVELTY_2026-10-15.md)确认 IEKT 已覆盖预测、观察回答、调整状态更新的基本链条。二元回答下 `sign(r-p)=2r-1`，残差符号一致率就是回答一致率，不能包装为额外方向信息；剩余的校准残差假设还须胜过普通门、回答趋势与校准对照。外部门与GRU内部门也可补偿，仅凭门参数符号不能解释真实学习。下面保留原假设及否证要求，不将其视为已确定的模型设计。

**假设。** 在相同历史窗口和参数预算下，将“历史支持程度”和“当前已观察回答造成的状态修正”分开处理，可减少少量异常回答带来的过度更新，从而改善短历史预测和总体AUC。

**最小候选。** 以验证选出的标准PyTorch序列基线为骨干，引入一个小的证据强度/更新权重模块。预测第t题时只能看t以前的回答；第t题答案只能在预测后用于更新。先实现一个模块及一个清楚的训练目标，不同时叠加图、扩散、LLM和多个专家。

**最相近方法。** [UKT](https://ojs.aaai.org/index.php/AAAI/article/view/35007)和[KeenKT](https://ojs.aaai.org/index.php/AAAI/article/view/39004)已研究不确定性与去噪；[MoC-KT](https://pykt.org/mockt)、[CDFKT](https://pykt.org/cdfkt)、RobustKT与FlucKT已区分长期变化和短期波动。因此，“给更新加门控”或“把知识和噪声分开”本身不构成原创贡献。

[本轮证据卡](evidence/UNCERTAINTY_KT_2026-10-14.md)补齐 UKT/KeenKT 主表，并在 KeenKT 指定公开整段前向发现不可见答案依赖。这使因果审计成为接入前置条件，但发现他人代码问题不自动使我们的门控假设新颖，也不能据此宣称模型超过其论文结果。

**进入实现前需明确的差异。** 模块究竟使用什么仅由过去可得的证据；它为何能处理最近邻方法的具体失败案例；相比相同参数量的普通门控/残差平滑，新增假设产生了什么可检验预测。若无法写清，不为它创造新模型名字。

**否证条件。** 收益只存在于人工翻转标签、只靠更多参数/更长历史、无法在预先指定的真实短历史子集重现，或总体AUC下降且校准无收益，则停止该假设。不得把“随机噪声鲁棒”写成识别学生真实心理原因。

## 3. 假设B：让稀疏题目向可靠的概念证据适度收缩

**假设。** 训练集中出现次数差异很大的题目，不应同样依赖自由题ID参数。通过只由训练数据估计的证据强度，调节题目特有表示与KC共享表示的贡献，可改善长尾题目的泛化，减少对头部题目的损失。

**最小候选。** 保留题目/KC两类表示，并加入可审计的频次条件收缩或正则项。统计量仅来自当前fold训练集。不得使用validation/test的正确率或交互频次；冷题ID应有预先定义的共享后备表示。没有独立题ID的数据集关闭题目分支，保留KC骨干，并报告此限制。

**原创性判断：当前宽泛机制偏弱。** [专项审计](evidence/ITEM_SHRINKAGE_NOVELTY_2026-10-14.md)已核到 SLC 2026 的逐题 empirical-Bayes 偏差收缩、Q-MCKT 的低频题对比学习、DKTT 的频繁/稀疏题共享动机，以及 AKT/simpleKT 的共享概念加题目差异项。训练期把题目残差收缩到 KC 中心与 SLC 的后处理偏差不同，但这个差异仍需证明价值，不能宣称首次使用题目收缩。

**必须对照。** 相同零初始化、普通权重衰减、固定共享/题目混合、按训练频次的简单手工混合、频次加权L2及同参数量基线。固定非零门 `g(n_q)u_q` 可换元为自由残差，未增加可表示函数集合；对 `u_q` 的L2等价于对残差施加 `lambda/g(n_q)^2` 加权惩罚，优化轨迹则未必相同。若拟加入 Q-MCKT 或 SLC，须先完成训练fold统计/独立calibration设计，不能在用于评分的同一验证标签上拟合校正器。没有额外文本的候选不与含文本方法直接归因比较。

**AS15 限制。** 本项目 manifest 为 `num_q=0, num_c=100`，不能检验独立题目参数收缩或 cold-item 效应；该集只能检验共同 KC 骨干。AS09/NIPS34 上的收益也不能自动外推为三个数据集都支持题目机制。

**否证条件。** 简单频次混合达到同样结果；收益依赖全数据统计；长尾收益由测试后选择阈值产生；或在AS09和NIPS34上方向不稳定，则不支持新增复杂模型。严格cold-item实验只作为另行登记的扩展，不能用warm-item结果代替。

## 4. 用验证集选择，不预先承诺某个结构

1. 先完成协议正确性检查和基础锚点，再按[证据账本](RESEARCH_LEDGER.md)筛出可运行、信息一致的强基线。
2. 研究候选必须在相同fold、seed、训练预算与输入信息下比较；同时报告参数量、显存和耗时。CPU通过前向/反向正确性检查后再使用本地RX9070XT 16GB。反向检查属于梯度计算，按持续授权登记并执行。
3. 在验证集选择整体AUC最有希望的候选。相对强基线的绝对AUC提高达到0.003（0.3个百分点），优先进入“整体预测提升”主线的完整确认计划；该数值是路线调整触发值，不是必须达成的承诺，也不是统计显著性的替代品。
4. 若提升不足0.3个百分点，但某困难场景有稳定证据，应在查看最终test之前登记场景、阈值、主指标和最近邻基线，并向用户说明依据。登记后不再更换场景追逐test结果。若没有可信信号，交付负结果并延长研究。
5. 最终只对冻结的新模型和验证选出的最强基线运行5-fold×3-seed，seed为42、2026、3407。新增本机训练、候选池调整和冻结后的正式测试均记录范围与依据，按持续授权执行，无需再次批准。
