# 假设 A：预测残差更新的近邻与可识别性限制

查证时间：2026-10-15 00:00–00:08，Asia/Hong_Kong（UTC+8）。本轮仅阅读公开原始论文、作者代码和项目现有文档；没有训练、模型前向、GPU 使用、学生数据扫描或质量指标。本文不改变 B003 的模型、配置或运行协议。

**判断：当前证据不足以将假设 A 选为原创主线。** IEKT 已直接覆盖“先预测，再结合预测回答与实际回答选择状态更新”的主链条；RobustKT 和 FlucKT 又覆盖了平滑、表示残差及其加权。更关键的是，二元回答下的残差符号由答案决定：`sign(r - p) = 2r - 1`（`0 < p < 1`）。因此，残差方向一致率就是回答一致率，不能充当区别于回答趋势的新证据。下面保留的原型最多是**校准／置信度加权的回答持续性假设**，尚未建立额外研究价值。

## 2. 可识别性修正：残差方向没有独立于答案的含义

对 `r ∈ {0, 1}`、`0 < p < 1`，有以下直接代数关系，无需实验才能成立：

```text
r = 1  =>  r - p > 0
r = 0  =>  r - p < 0
sign(r - p) = 2r - 1
r - p = (2r - 1) * abs(r - p)
weighted_mean(r - p) = weighted_mean(r) - weighted_mean(p)
```

最后一个等式要求两边使用完全相同的历史、权重和归一化。第 3 节每个有历史支持的 KC 的 `S_c / W_c` 正是这种加权均值；再跨 KC 平均也保留该等式。若概率数值饱和到 0 或 1，可能出现零残差，这不产生可作为新机制的独立方向信息。

因此，“连续同向残差”按纯符号定义时，只是在重新命名连续相同的回答。即使历史预测概率不同，符号也不变。平均残差 `m` 可以不同于原始正确率，但差异来自减去平均预测概率；它最多表征这段历史中的概率校准偏差或置信度加权的回答持续性。平均残差的正负也不能证明发生了学习或识别真实回答噪声。

**仅可保留的探索问题**是：在控制回答趋势、平均预测概率、残差幅度与普通门控后，利用这些统计调节状态更新，是否比简单校准或平滑有额外价值？这不是残差符号提供了新信息。将 `mean(r-p)` 改写为 `mean(r)-mean(p)` 是等价实现，不是应期待不同结果的消融。

本轮既没有这种额外价值的实证，也没有排除贝叶斯过滤、在线预测校正及其他更新模型的已有机制。**不能据此确定原创主线，也不能宣称首次提出、优于 IEKT 或识别了学生心理原因。**

## 3. 保留用于否证的原型定义，非当前原创主线

以下定义仅保留为可复查的候选记录，未实现；不据此启动新模型或改变 B003。它使用一个事件级 GRU 骨干，增加 **4 个标量参数**，但参数少和实现明确不构成新颖性证据。

### 输入与严格先后次序

事件 `t` 只包含可选题 ID、去重后的 KC 集合 `C_t` 和回答 `r_t`。题表示可用题 ID 嵌入与 KC 嵌入的均值；AS15 关闭独立题 ID 分支，不能伪造题 ID。预测顺序固定为：

1. 用更新前状态 `h_(t-1)` 和当前查询表示 `v_t` 得到 `p_t`。
2. 当前事件评分／损失使用这个 `p_t`；此时不可读取 `r_t`。
3. 观察 `r_t` 后形成 `e_t = r_t - stop_gradient(p_t)`，计算门与候选更新；只影响后续预测。
4. 完成更新后才把本次残差写入 KC 统计。计算本次门时用的是 `t` 之前的统计。

`stop_gradient` 避免门控路径直接通过残差对当前预测头反传；它不保证校准或心理可解释性，后续损失仍能经状态路径影响模型。第一事件可以形成先验预测供后续残差使用，但是否参与训练损失须与对照统一，不能偷偷多一个监督目标。

### 只维护可见历史的统计

每个 KC 保存有符号残差和 `S_c`、绝对残差和 `A_c`、权重和 `W_c`、未衰减支持量 `N_c`，初始均为零。使用一个事先固定的衰减 `lambda`，例如 `0.8`；首轮不搜索多个窗口和衰减组合。每次该 KC 出现时，事件权重 `w = 1 / |C_t|`，在门计算之后更新：

```text
S_c <- lambda * S_c + w * e_t
A_c <- lambda * A_c + w * abs(e_t)
W_c <- lambda * W_c + w
N_c <- N_c + w
```

衰减按该 KC 的再次出现计数，不宣称是真实时间遗忘。多 KC 事件共享同一个 `e_t`，总计一次事件权重；绝不把一个真实答案当作多个独立证据。它也不能识别本次究竟哪个 KC 造成预测误差。

门读取当前 `C_t` 上各统计的均值：`m_t = mean(S_c / W_c)`、`a_t = mean(A_c / W_c)`、`n_t = mean(N_c)`；`W_c=0` 时相应比值定义为零。令：

```text
support_t = n_t / (1 + n_t)
calibration_interaction_t = support_t * e_t * m_t / (a_t + epsilon)
g_t = sigmoid(b + w_n * support_t + w_e * abs(e_t)
                + w_p * calibration_interaction_t)
u_t = GRUCell(concat(v_t, r_t), h_(t-1))
h_t = h_(t-1) + g_t * (u_t - h_(t-1))
```

新增参数只有 `b, w_n, w_e, w_p`，不预设它们必须符合认知解释。`g_t` 在 0–1 之间，只在旧状态与原 GRU 候选之间插值；GRU 本来已有门，因此“再加一个门”不是贡献。`calibration_interaction_t` 只是当前回答残差与历史平均校准偏差的乘积，不能命名为独立的“残差方向证据”。

**外部门也不可单独解释为实际更新强度。** 按 GRU 保留门 `z_t` 的写法，`u_t = z_t * h_(t-1) + (1-z_t) * candidate_t`，则外部门后的变化为 `g_t * (1-z_t) * (candidate_t-h_(t-1))`。两层门和候选状态可以共同补偿。因此 `w_p > 0`、`g_t` 增大或门与某特征相关，都不能单独证明实际更新增强。若将来研究这一机制，至少应检查实际变化 `||g_t * (u_t-h_(t-1))||`，并固定同一骨干、旧状态和候选状态，干预门特征以隔离门的作用；范数变化本身仍不是认知机制证据。当前能提出的检验仅是同预算预测消融，不能据参数符号作机制结论。

### 窗口与执行成本是硬约束

- 每个目标仍取 v2 的完整事件连续历史后缀，历史与目标的去重 KC 总数不超过 200。只在该后缀内重放状态和残差统计；不能从窗外缓存 `h/S/A/W/N`，也不能复用用更长历史计算过的旧 `p_i`。窗口起点变化时，历史残差也必须重算。
- 在一次给定上下文的重放中，每个真实事件只更新一次、只产生一个概率；同题多个 KC 的次序不应改变结果。**事件级训练合同尚未定义**，尤其是首事件是否监督、重叠窗口中的同一目标是否重复计损及如何加权、哪些历史预测仅用于形成残差而不计损。因此目前也不能承诺“一次真实事件恰好一次训练损失”。不能悄悄继承 B003 的重复 KC 训练，再把表示或监督差异归因于门控。若以后继续，所有原型消融必须先共用明确合同；B003 保持原样。
- 逐步 GRU 能实现“自己的预测→观察回答→门→下一状态”。整段 Transformer 的同一遍预测又依赖被门修改的历史表示，直接回填会形成循环依赖。若改成两遍预测或额外教师，必须登记额外计算／参数／梯度路径并设置同成本对照；本原型没有解决这个接入问题。
- 滑动窗口逐目标重放可能显著增加时间。本轮没有性能测量；不能承诺原型与当前批量 Transformer 等速。若其成本不合理，应先否决该实现，不能通过扩大可见历史来提速。

## 4. 最小对照与停止条件

若以后出现独立理由重新考虑该原型，以下是必要否证对照，不是本轮训练安排。不新增复杂骨干、文本、时间特征、伪标签或多专家来回避当前可识别性问题。

| 对照 | 要排除的普通解释 |
|---|---|
| 同骨干原始 GRU，无外部门 | 是否仅靠加门而有用；如本身明显落后强基线，不能用小消融收益替代整体竞争力。 |
| **4 参数普通门**：`sigmoid(b + w_1 support + w_2 p + w_3 r)` | 是否只要普通预测／回答门控就够；参数数目与候选完全一致。 |
| **4 参数幅度门**：特征换成 `support, abs(e), a` | 历史平均校准偏差是否提供超出残差大小／平滑强度的价值。 |
| **4 参数回答趋势门**：保留 `support, abs(e)`，最后一项使用 `support * e * mean_past(r - 0.5)` | 是否只是原始正确率持续性；使用同样 KC 权重、窗口和衰减。 |
| 回答均值与预测均值的显式校准对照 | 必须控制 `mean_past(r)` 与 `mean_past(p)`；它们的差就是 `m`，不能仅战胜不读取历史预测概率的回答趋势门，就宣称发现独立残差信息。若门使用更多参数，如实报告。 |
| 固定／单参数学习的状态插值；另设仅预测输出校正的小对照 | 是否只是降低更新步长或校准概率；这些不是 4 参数完全匹配，须如实报告，不能填充无效参数凑数。 |

所有门中使用的预测概率均作相同的 `stop_gradient`，不能让普通门额外获得一条预测头梯度路径。所有控制共用初始化、损失、窗口、事件权重和训练预算。输出校正若要拟合参数，只用训练侧独立划分；不在用于报分的同一验证标签上拟合校正器。

IEKT 是应优先补齐的外部机制基线；其采样推理、公共输入适配、窗口与预算尚需单独审计。本轮不能把上述普通门称为完整 IEKT 复现。RobustKT／FlucKT 是平滑类外部参照，启用分支和协议须固定，不据抽象机制选择一个弱配置充当作者方法。

验收与否证顺序：

1. **先做合成因果契约。** 固定权重且关闭 dropout：翻转当前答案不改变当前及更早预测，允许改变后续状态；未来答案／题目变化不影响更早输出；当前答案只在评分后被读取；窗口起点、KC 去重／排列、独立学生重置、padding 全部有独立检查。通过这些检查只说明指定实现与输入合同相符，不是研究创新。
2. **分层不能制造独立机制。** 删除“残差方向一致率”分组支持新机制的方案：它与答案一致率是同一个分组。若后续做探索性诊断，须明确分层属于历史回答模式、预测置信度／校准统计或短历史，不能将其差异归因于独立残差方向。分组只依赖目标之前的信息；每组报告学生数、事件数、类别比例，单类别组不报 AUC。规则、阈值与参考预测模型须在正式测试前冻结。
3. **用真实验证数据排除普通解释。** 候选须面对普通门、幅度门、回答趋势门及显式校准对照。若收益由回答持续性、预测均值校正、输出校准、额外监督或额外历史／参数／搜索预算解释，则不支持新增状态更新机制；即使存在收益，也不能推翻上述代数等价性。训练阶段看到的残差没有跨拟合属性，不能称为独立噪声估计；若改用教师／OOF 预测，应另登记成本与数据边界。
4. **对总体质量保持要求。** 人工翻转回答只作诊断，不替代真实场景收益。只有子集改善而总体 AUC 下降时，不支持目前的整体提升目标；不能测试后换子集。0.003 的绝对 AUC 提升是项目已有路线调整触发值，不是承诺，也不等于统计显著性。
5. **阶段结论。** 原型与消融同训练表示、同 fold/seed、同监督和预算；相对 B003 强模型的结果属于整体模型比较，不能直接归因于此门。最终比较仍需独立验证选点、冻结候选及分析，再走已有多 fold/seed 与配对学生统计协议。

**当前证据不足以将该候选选为原创主线。** 残差符号与二元答案的等价性已经排除了原先的“方向提供独立信息”论证；外部门与 GRU 的补偿、事件级训练与重叠窗计损合同未定义，也阻止了明确的机制归因。保留原型和对照只为防止重复包装普通门控、回答趋势或校准；在没有额外问题证据及最近邻差异之前，不推进为原创模型。普通解释达到同样效果时，应记录负结果。
