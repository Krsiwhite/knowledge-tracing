# 共享验证预测的误差分层

本工具为原创研究选择问题提供描述性证据。它读取已完成运行的保存预测及原始开发数据 `train_valid.csv`，不加载模型或权重，不进行推理、反向计算或训练，不读取测试文件。它与只读预测工件的 `analyze_shared_predictions.py` 分开维护，因为历史长度和训练题频次需要额外的数据来源。

## 分层在读取真实分层结果前固定

以下四组分别统计，不进行交叉筛选。边界于 2026-10-15 固定，随后才执行首个 AKT/ASSIST2009 诊断。

| 分层 | 固定区间 | 定义 |
| --- | --- | --- |
| 可见历史事件数 | 1–5、6–20、21–50、>50 | 当前目标在共享 KC200 协议内实际可见的作答事件数 |
| 训练题目频次 | 0、1–5、6–20、21–100、>100 | 当前 fold 训练学生的 canonical 作答事件中，该题出现的次数 |
| 可见历史中的同题支持 | 0、至少1次 | 可见历史中是否出现当前题目 |
| 可见历史中的 KC 支持 | 0、至少1次 | 是否存在一个历史事件，其 KC 集合与当前题目 KC 集合相交 |

历史按作答事件计数，多 KC 作答不重复计数。历史不是学生全部过去记录；KC200 截断之外的事件不可见。训练题频次包括训练学生的第一个事件，只使用非验证 fold，不能从验证出现次数替代。没有独立题目 ID 的数据集明确不支持两个题目分层，不把 KC 或占位 ID 当作题号。

## 输入与校验

```bash
PYTHONPATH=src python scripts/diagnose_shared_errors.py \
  --run-dir /path/to/main/runs/B003-akt-assist2009-f0-s42 \
  --batch /path/to/main/configs/batches/B003-shared-convergence-baselines.json \
  --output reports/B003_AKT_ASSIST2009_ERROR_STRATA_2026-10-15.json
```

运行目录必须已完成，且属于指定公开批次。复用预测分析工具核验配置、数据清单、实现和预测收据；读取保存配置绑定的数据清单，重新构建完整共享验证目标。每个目标按学生与事件身份匹配，另外核对题号、KC 数、目标与历史摘要及当前标签。目标摘要不包含当前标签，不能代替标签校验。

训练频次和验证上下文来自同一份有哈希约束的开发源文件。输出记录所读工件、开发源、清单及诊断实现的摘要，结束时复查输入未发生变化。输出不包含学生 ID、逐题或逐事件记录，也不覆盖已有报告。

## 如何解释

每层报告事件数、涉及学生数、正例比例、AUC、NLL、Brier、准确率和固定15箱 ECE。空层指标为空；单类层 AUC 为空。学生可以出现在多个层，因此不能相加各层学生数当成总学生数。

这些层的学生、题目和正例比例不同。某层 AUC 较低不能单独证明“长尾导致模型失效”或“短历史存在认知噪声”；同样，层间 NLL/Brier 的差异也受到标签分布影响。这里不输出 p 值、显著性结论或噪声/猜测等心理标签。

验证集已经用于选检查点，此次分层还会用于探索研究方向，不能当作最终确认。首个模型的单 fold、单 seed 结果仅用于提出问题；后续应在相同目标上比较强基线，确认问题仍存在，再登记最小候选、消融和最终测试分析。没有稳定证据时保留负结果，不为局部现象创造模型名称。
